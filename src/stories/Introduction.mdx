# React 3D Flipbook Library

A modern, feature-rich React library for creating interactive 3D flipbook/page-turning effects with WebGL and CSS3D support.

## ✨ Features

- **🎨 Multiple Themes** - Dark, light, and gradient skins out of the box
- **📱 Touch Support** - Swipe gestures for mobile devices
- **🔍 Zoom Controls** - Pinch-to-zoom and button controls
- **📑 Bookmarks** - Save and recall favorite pages
- **⬅️ RTL Support** - Right-to-left page order for Arabic, Hebrew, manga
- **📄 View Modes** - Single page and double page spread modes
- **🖥️ Fullscreen** - Immersive fullscreen viewing experience
- **⌨️ Keyboard Navigation** - Arrow key support
- **🎯 Accessibility** - ARIA labels and keyboard support
- **📦 TypeScript** - Full TypeScript support with type definitions

## 📦 Installation

```bash
npm install react-3d-flipbook
# or
yarn add react-3d-flipbook
```

## 🚀 Quick Start

```tsx
import { Flipbook } from 'react-3d-flipbook';
import 'react-3d-flipbook/dist/styles.css';

const pages = [
  { src: '/images/page1.jpg', title: 'Cover' },
  { src: '/images/page2.jpg', title: 'Introduction' },
  { src: '/images/page3.jpg', title: 'Chapter 1' },
];

function App() {
  return (
    <Flipbook
      pages={pages}
      width={800}
      height={600}
      skin="dark"
      onPageFlip={(e) => console.log('Page:', e.page)}
    />
  );
}
```

## 🔧 Configuration

### Button Configuration

Each toolbar button can be individually configured:

```tsx
<Flipbook
  pages={pages}
  btnFirst={{ enabled: true, title: 'Go to first page' }}
  btnPrev={{ enabled: true, title: 'Previous' }}
  btnNext={{ enabled: true, title: 'Next' }}
  btnLast={{ enabled: true, title: 'Go to last page' }}
  btnZoomIn={{ enabled: true }}
  btnZoomOut={{ enabled: true }}
  btnBookmark={{ enabled: true }}
  btnExpand={{ enabled: true }}
/>
```

### Zoom Settings

```tsx
<Flipbook
  pages={pages}
  zoomMin={0.5}
  zoomMax2={4}
  zoomStep={0.25}
/>
```

## 🎮 Programmatic Control

Use a ref to control the flipbook programmatically:

```tsx
import { useRef } from 'react';
import { Flipbook, FlipbookInstance } from 'react-3d-flipbook';

function App() {
  const flipbookRef = useRef<FlipbookInstance>(null);

  return (
    <>
      <button onClick={() => flipbookRef.current?.nextPage()}>
        Next Page
      </button>
      <Flipbook ref={flipbookRef} pages={pages} />
    </>
  );
}
```

### Available Methods

| Method | Description |
|--------|-------------|
| `nextPage()` | Go to next page |
| `prevPage()` | Go to previous page |
| `firstPage()` | Go to first page |
| `lastPage()` | Go to last page |
| `goToPage(n)` | Go to specific page |
| `zoomIn()` | Increase zoom |
| `zoomOut()` | Decrease zoom |
| `zoomTo(level)` | Set specific zoom level |
| `toggleFullscreen()` | Toggle fullscreen mode |
| `getCurrentPage()` | Get current page number |
| `getNumPages()` | Get total page count |
| `getZoom()` | Get current zoom level |

## 📝 Page Configuration

Each page object can have the following properties:

```tsx
interface FlipbookPage {
  src: string;           // Image URL
  thumb?: string;        // Thumbnail URL
  title?: string;        // Page title
  htmlContent?: string;  // HTML overlay content
  empty?: boolean;       // Mark as empty/blank page
  side?: 'left' | 'right'; // Side of spread
}
```

## 🌐 RTL Support

For right-to-left languages or manga-style reading:

```tsx
<Flipbook
  pages={pages}
  rightToLeft={true}
/>
```

## 📄 Single Page Mode

Display one page at a time:

```tsx
<Flipbook
  pages={pages}
  singlePageMode={true}
/>
```

## 🎯 Events

| Event | Type | Description |
|-------|------|-------------|

| `onZoomChange` | `{ zoom }` | Zoom level changed |
| `onFullscreenChange` | `{ isFullscreen }` | Fullscreen toggled |
| `onReady` | `void` | Flipbook initialized |
